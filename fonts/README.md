# Fonts

Both fonts are from the Noto project and are licensed under the SIL Open Font License 1.1.

- `NotoSansCuneiform.woff2`: cuneiform signs for the Hammurabi "signs" picture. License: `OFL-LICENSE.txt`.
- `NotoSansEgyptianHieroglyphs-ptolemy.woff2`: a subset of Noto Sans Egyptian Hieroglyphs (from the `@fontsource/noto-sans-egyptian-hieroglyphs` package, v5.3.0) with only the seven signs of Ptolemy's name, for the Rosetta Stone "cartouche" picture (about 5 KB). License: `OFL-LICENSE-EgyptianHieroglyphs.txt`.
